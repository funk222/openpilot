## 14. 试驾与 Car Unreconized 问题诊断（当前）

### 14.1 现象
- 试驾后系统进入 Dashcam mode（Car Unreconized）
- 有时能显示速度，有时不能

### 14.2 根本原因
系统在启动时需要通过"CAN 指纹识别"来确定车型。流程如下：
1. 启动后扫描 CAN 总线 2 秒左右
2. 收集扫过的所有报文 ID
3. 与预存的车型"指纹"（FINGERPRINT）数据库对比
4. 如果找到唯一匹配，则识别为该车型；否则转为"mock"模式（Dashcam）

我们的 Arduino ECU 虽然发送了关键报文（如 WHEEL_SPEEDS、PCM_CRUISE 等），但：
- 可能**缺少某些低频报文**（例如 GEAR_PACKET、STEER_ANGLE_SENSOR、STEER_TORQUE_SENSOR 等）
- 或**报文 ID 不完全匹配**官方 Corolla 的预期 ID 集合

因此系统无法将其识别为真实 Corolla，自动降级到 Dashcam 模式。

### 14.3 已实施解决方案（代码已推送）
在 `launch_env.sh` 中强制指定车型指纹：
```bash
export FINGERPRINT="TOYOTA COROLLA 2017"
export SKIP_FW_QUERY="1"
```

优点：
- 跳过自动识别，直接使用 Corolla 参数集
- 加快启动速度（无需等待 2 秒扫描）
- 避免因 Arduino 报文集不完整导致的识别失败

### 14.4 后续改进方向（可选）
如果仍有问题，再逐步补充缺失的报文到 Arduino：
- 补充 STEER_ANGLE_SENSOR（0x260）报文
- 补充 STEER_TORQUE_SENSOR（0x260）报文
- 调整低频报文的发送周期
- 增加报文的内容有效性检查

### 14.5 下一步
待 EON 重新连接后（可能在试驾结束后），将最新代码推送到设备并重启，系统应该能进入 ACC/LKA 模式而不是 Dashcam。

## 17. Steering Temporarily Unavailable 诊断（2026-10-22，当前）

### 17.1 现象
- openpilot 能 engage，但不会真正 selfdrive steering
- 有时显示 `Steering temporarily unavailable`
- 车速、状态和命令计数看起来像是“已进入 enabled/active”，但方向并不物理执行

### 17.2 关键确认
- 代码中 Toyota 默认 `minSteerSpeed = 0.0`，并不是当前主问题
- 实机读取到的运行时参数如下：
  - `carFingerprint = TOYOTA COROLLA 2017`
  - `minSteerSpeed = 0.0`
  - `minEnableSpeed = -1.0`（已在 single-CAN 特判下绕过最低启用速度门槛）
- 因此，低速门槛不是当前导致 steering 不工作的决定性原因

### 17.3 根因判断（已验证）
- 日志中 `sendcan` / `sc2e4` 明确在增加，说明 openpilot 向 Panda 发送了 `0x2E4 STEERING_LKA` 命令
- 但同一时窗中 `carSide can2e4` 始终为 0，说明该命令没有出现在车侧总线/执行总线
- 也就是说：
  - 不是 control loop 不发命令
  - 也不是 `minEnableSpeed` 锁死
  - 而是 **命令链路在总线层断掉了**，命令发到了 sendcan 但没到真正的 EPS/车身总线

### 17.4 证据说明
- 关键日志字段：
  - `state=enabled en=1`
  - `active=1`
  - `actSteer=1.000`（几秒内发生）
  - `sc2e4` 持续增长
  - `can2e4=0` 持续为 0
- 这意味着 openpilot 认为自己已输出 steering command，但总线层没有看到真实 EPS 侧的帧，因此 `steering` 无法执行

### 17.5 工作结论
- 当前最可能的故障点：
  1. Toyota single-CAN 拓扑下，0x2E4 没有正确发往执行总线
  2. 或者 panda/Arduino/总线桥接没有把该帧转发到 EPS 可见总线
  3. 或者某些 custom ECU 报文优先级/回路导致命令被遮断
- 这已经不是单纯“没有 engage”或者“没有 CRC”问题，而是**命令到达总线层失败**的典型问题

### 17.6 试验型修正（已在代码中处理）

  - 单 CAN 下让 `STEERING_LKA` 0x2E4 尝试双发（bus 0 和 bus 1）
- 目的：
